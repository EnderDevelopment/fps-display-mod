# FPS Display Mod

Display your FPS in real-time on your Minecraft Bedrock screen.

## Features

- Real-time FPS display
- Customizable position and color

## Requirements

- Minecraft Bedrock Edition 1.20.4
- Fabric Loader 0.14.0 or later
- Fabric API

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/fps-display-mod/releases).
2. Place the mod file in your `mods` folder.
3. Launch Minecraft Bedrock Edition with Fabric Loader.

## Usage

Once installed, the mod will automatically display your FPS in the top-left corner of your screen. To customize the position or color, you will need to modify the source code.

## Configuration

The mod does not have a configuration file. To customize the position or color, you will need to modify the source code in the `FPSModClient.java` file.
